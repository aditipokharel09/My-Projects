Python · NumPy · OpenCV · MediaPipe

Sanket: real-time hand gesture recognition

A perceptron and a multilayer perceptron, both written from scratch in NumPy, classify five hand gestures from a live webcam. MediaPipe supplies 21 hand landmarks (42 numbers), and the on-screen overlay shows confidence for every class. I checked my backpropagation against scikit-learn, then replaced synthetic data with samples I captured myself to fix confusion between similar gestures.

5gestures
100%perceptron, fist vs open palm
93–99%live confidence
PythonNumPyOpenCVMediaPipe
Case study: how it was built
Problem
Neural-network demos usually run on fixed datasets. I wanted one that reacts to a live, moving hand.
Approach
MediaPipe turns each webcam frame into 21 landmarks (42 numbers), so a small perceptron and MLP can classify them without convolutional layers.
What I built
A capture tool to record labelled samples, the from-scratch NumPy models, and a live overlay showing confidence for all five gestures.
Challenges
A model trained on synthetic data failed on a real hand, and one capture session ended after 3 samples. Peace and Pointing also scored high together, so I recorded 100 to 200 more varied real samples per gesture and retrained.
Results and limits
The perceptron converged in 2 epochs on Fist vs Open Palm, and my MLP matched scikit-learn on the synthetic set. Live confidence was 93 to 99%. It handles one hand and five static gestures, and lighting affects it.

SajiloDocs AI: document helper

Upload a PDF and get a simple explanation, the important dates and a checklist of next steps, in English or Nepali. Ask follow-up questions about the document and download the summary. Built for people who find official paperwork hard to read.

2languages
3×auto-retry on API errors
PythonStreamlitGemini APIPDF parsing
Case study: how it was built
Problem
Official documents are long and hard to read, especially for people who prefer Nepali.
Approach
Extract the PDF text, send it to Gemini with a prompt for a simple explanation, key dates and next steps, in English or Nepali.
What I built
A Streamlit app with PDF upload, page and character counts, a summary tab, a question-and-answer chat about the document, and a summary download.
Challenges
Gemini sometimes returned 429, 500, 503 or 504 errors. I added up to 3 attempts with a growing wait (2 s, then 4 s) and clear error messages.
Results and limits
It works end to end as a v0.2 prototype. Only the first 15,000 characters of a document are sent, and scanned PDFs without text are not supported.

Nagarik Sewa Kendra: citizen services portal

A bilingual (English and Nepali) portal prototype where citizens request government documents, track their applications and file grievances. A separate municipal dashboard lets officers review each request and update its status, and a sample certificate can be previewed and printed.

6document services
2languages
2roles: citizen & officer
HTMLTailwind CSSJavaScriptResponsive UI
Case study: how it was built
Problem
Getting a government document usually means queues and unclear status.
Approach
One portal where a citizen requests a service, follows its status and files a complaint, while an officer reviews the same data.
What I built
A single-page app in HTML, Tailwind CSS and vanilla JavaScript: sign-in, a request form with ward selection, a status tracker with timeline, grievances, an officer review queue, a certificate preview and an English/Nepali toggle.
Challenges
Keeping every screen in sync after a status change, and translating dynamic content as well as static text.
Results and limits
All flows work with sample data. It has no real backend and is not connected to any government system.
